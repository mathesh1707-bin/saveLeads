# SaveLeads

A simple Chrome extension to save website URLs and bookmark the current browser tab.

## Features
- Save URLs manually.
- Save the currently active browser tab.
- Store saved URLs using Local Storage.
- Display saved URLs as clickable links.
- Clear all saved leads.

## Technologies Used
- HTML
- CSS
- JavaScript
- Chrome Tabs API
- Local Storage

## Installation
1. Clone this repository.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable Developer Mode.
4. Click **Load unpacked**.
5. Select the project folder.

## Learning Outcomes
Built this project to practise JavaScript fundamentals, DOM manipulation, event handling, arrays, and Local Storage.
